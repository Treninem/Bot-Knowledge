# Правила пополнения Bot-Knowledge

## Можно добавлять
- обезличенные языковые паттерны;
- варианты формулировок и тонов;
- общие намерения пользователя;
- правила ведения диалога;
- безопасные шаблоны модерации;
- обобщённые уроки, подтверждённые на нескольких случаях.

## Нельзя добавлять
- сырые переписки и цитаты из приватных сообщений;
- Telegram/VK/Discord ID, usernames, телефоны, e-mail;
- имена конкретных пользователей;
- токены, ключи, cookies и иные секреты;
- память отдельной группы, компании или проекта;
- неподтверждённые «знания», полученные из одной реплики.

## Поток обучения
1. Каждый бот обучается локально и сохраняет локальную память отдельно.
2. Из повторяющихся случаев формируется обезличенный кандидат.
3. Кандидат проверяется на отсутствие персональных данных и секретов.
4. Только после проверки шаблон вручную или доверенным пайплайном попадает в Bot-Knowledge.
5. Боты получают новую утверждённую версию только на чтение.

Так общая база становится умнее, но чаты разных пользователей не смешиваются.

## Дополнительный порядок для будущих навыков
- Все навыки — **декларативные**: короткие нейтральные шаблоны поведения/условия уместности без исполняемого кода и полномочий применять санкции.
- Каждый кандидат проходит проверку на приватность, уникальные цитаты, персональные детали, ошибочные рекомендации, чрезмерную навязчивость и попытку инструкцией обойти настройки бота.
- Публичный GitHub нельзя использовать как архив сообщений: удаление из следующей версии не гарантирует удаления из git history. Ручная проверка обязательна даже после автоматической очистки.
- Из чатов допустимы лишь безопасные **обобщённые подтверждённые навыки**; если есть сомнения, кандидат отклоняется. Не загружать общую базу напрямую из BotHost и не выдавать токены записи хостингу.
- Порядок, критерии и предлагаемые пакеты: [docs/APPROVED_SKILLS_ROADMAP.md](docs/APPROVED_SKILLS_ROADMAP.md). До реализации импорта/валидации у ботов изменения являются **планом**, а не автоматически работающей способностью.
