# Bot-Knowledge

Общая бесплатная база знаний и языковых шаблонов для ботов Treninem.

## Назначение

Этот репозиторий хранит только переносимые между ботами знания: распознавание намерений, стили общения, нейтральные формулировки, диалоговые шаблоны и безопасные правила ответа.

## Важное правило приватности

В репозиторий нельзя загружать сырые переписки, Telegram ID, usernames, имена пользователей, токены, секреты, персональные профили, содержимое приватных чатов и данные конкретных сообществ.

Каждый бот хранит память конкретного чата локально. В общую базу допускаются только обезличенные и проверенные паттерны, которые полезны любому боту.

## Структура

- `manifest.json` — версия и список пакетов.
- `packs/ru/intents.json` — русские намерения и фразы.
- `packs/ru/styles.json` — стили и тон общения.
- `packs/ru/dialogue.json` — универсальные диалоговые реакции.
- `packs/ru/safety.json` — безопасное различение опасной инструкции и обсуждения/жалобы.
- `schema/manifest.schema.json` — схема манифеста.
- `POLICY.md` — правила пополнения базы.

## Подключение ботов

Боты должны:

1. Иметь встроенный локальный fallback.
2. Загружать `manifest.json` по HTTPS.
3. Проверять версию схемы и SHA-256 каждого пакета.
4. Кэшировать последнюю валидную версию локально.
5. Никогда не прекращать работу из-за недоступности GitHub.
6. Не отправлять накопленную локальную память обратно автоматически.

Текущая схема пакета: `1`.

## План развития: общие умения и безопасное пополнение

ImPULS **уже использует** четыре проверяемых SHA-256 языковых JSON-пакета этого репозитория (только чтение, кэш и fallback). Новые переносимые умения — поддержка, поздравления, уместный юмор, вопросы по правилам, объяснение возможностей бота и контекстное различение нарушений — спланированы в [docs/APPROVED_SKILLS_ROADMAP.md](docs/APPROVED_SKILLS_ROADMAP.md).

**Пока это только план.** Бот не выгружает сюда знания из чатов автоматически. Repo публичный: личные данные, сырые реплики, локальные правила и истории санкций должны оставаться в приватной базе бота. Кандидаты на общие навыки допускаются только после обобщения, проверки и утверждённого PR. Новые пакеты потребуют отдельного обновления загрузчика ImPULS и тестов.

## Общая база для всех ИИ-ботов Treninem

Обязательное правило проекта — [AGENTS.md](AGENTS.md). Все новые боты с ИИ используют здесь проверенные общие навыки вместо обучения с нуля, при этом персональный/чатовый контекст хранится только у конкретного бота. GitHub — источник **версионных снимков знаний**, не оперативная транзакционная база.

В манифест добавлен `packs/ru/skills.json` — 7 первоначальных обезличенных универсальных навыков для поздравления, соболезнования, деэскалации, безопасного юмора, уточнения правил, объяснения функций и умения промолчать. Они не выдают административных полномочий и не делают бота самопроизвольно разговорчивым. Для их применения нужен отдельный безопасный потребитель в боте.

Проверка реального HTTPS-чтения и скорости локального доступа: `python scripts/benchmark_shared_skills.py`. Цель 1–3 секунды на сетевое обновление не гарантируется сетью; рабочие ответы идут из локального кеша, поэтому GitHub не участвует в каждом сообщении.
