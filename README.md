# Bot-Knowledge

Общая бесплатная база знаний и языковых шаблонов для ботов Treninem.

## Назначение

Этот репозиторий хранит только переносимые между ботами знания: распознавание намерений, стили общения, нейтральные формулировки, диалоговые шаблоны и безопасные правила ответа.

## Важное правило приватности

В репозиторий нельзя загружать сырые переписки, Telegram ID, usernames, имена пользователей, токены, секреты, персональные профили, содержимое приватных чатов и данные конкретных сообществ.

Каждый бот хранит память конкретного чата локально. В общую базу допускаются только обезличенные и проверенные паттерны, которые полезны любому боту.

## Структура

- `manifest.json` — версия и список пакетов.
- `packs/ru/intents.json` — русские намерения и фразы.
- `packs/ru/styles.json` — стили и тон общения.
- `packs/ru/dialogue.json` — универсальные диалоговые реакции.
- `packs/ru/safety.json` — безопасное различение опасной инструкции и обсуждения/жалобы.
- `schema/manifest.schema.json` — схема манифеста.
- `POLICY.md` — правила пополнения базы.

## Подключение ботов

Боты должны:

1. Иметь встроенный локальный fallback.
2. Загружать `manifest.json` по HTTPS.
3. Проверять версию схемы и SHA-256 каждого пакета.
4. Кэшировать последнюю валидную версию локально.
5. Никогда не прекращать работу из-за недоступности GitHub.
6. Не отправлять накопленную локальную память обратно автоматически.

Текущая схема пакета: `1`.
