## Реальная граница совместимости
Публичный manifest остаётся с 38 пакетами и не регистрирует staging. Потребитель должен отдельно поддержать выбор условных дополнительных реплик, разграничить примеры и инструкции и подтвердить размер загружаемого снимка. Реализацию приватного ImPULS отсюда **не меняли** и её детали не публикуем. Тесты GitHub Actions применять только к актуальному полному PR head SHA; проверенный пост-merge SHA публиковать отдельно.

**Следующий приоритет:** дождаться фактического exact-head CI; при успехе и безопасном режиме публикации рассмотреть merge отдельно от активации в потребителях. При отсутствии подтверждённой совместимости нельзя заявлять, что живой ImPULS получил новые ответы.
