# RU/EN: контролируемое сохранение смысла при переформулировании

Статус: исполняемый детерминированный эталон, а не новая языковая модель.

В packs/ru/meaning_paraphrases.json находятся 48 оригинальных синтетических случаев (24 RU и 24 EN), 96 отличающихся правильных вариантов в тонах neutral/casual и 48 контрастных примеров заведомо неверной передачи смысла. Категории: отрицания, условия, степень уверенности, разрешение, точные числа, единицы, границы исправлений, сроки, ответственность, исправление ошибки и другие.

Команда:
python scripts/paraphrase_meaning.py --addressed --source "Не отправляй отчёт, пока я его не проверю." --tone casual

Английский:
python scripts/paraphrase_meaning.py --addressed --language en --source "The deadline is Thursday, not Tuesday."

Проверка:
python scripts/validate_pack.py
python scripts/test_paraphrase_meaning.py

MeaningParaphraser читает только проверенный по manifest/SHA-256 пакет. Выбор допускается для полной, заранее утверждённой фразы; меняется только регистр и лишние пробелы. Неизвестные, приблизительные или сомнительные входы получают unknown_source вместо рискованной догадки. Отдельно проверяются адресация, язык, тон, чувствительный контекст и ограниченный список последних восьми ответов. Контрастный НЕПРАВИЛЬНЫЙ текст никогда не используется для ответа и не индексируется как утверждённая переформулировка.

Описания semantic_guard написаны людьми и помогают аудиту; программа не доказывает смысловую эквивалентность новых произвольных строк. Никаких санкций, выполнения действий, чтения частной памяти или GitHub-записи. Новые 48 источников входят в локальный поиск (561 → 609 записей). Подключение к ImPULS и AuroraFox требует отдельных consumer PR, интеграционных и регрессионных испытаний.
