# Локальный поиск прагматических выражений

В `scripts/search_knowledge.py` добавлен индекс `pairs` из `packs/ru/pragmatic_contrasts.json`. Ранее индекс содержал 403 записи; теперь содержит 451 запись, включая 48 контрастных выражений на русском и английском.

Точное совпадение выражения получает приоритет перед частичным совпадением слов. Фильтрация аудитории применяется до выдачи результатов.

Команды проверки:

```
python scripts/search_knowledge.py --query "Отличная работа."
python scripts/test_pragmatic_search.py
```

Тест проверяет 48 результатов, фильтрацию аудитории и десять структурных повторов. Этот инструмент не заменяет понимание естественного языка и не подключает изменения к работающим программам автоматически.
