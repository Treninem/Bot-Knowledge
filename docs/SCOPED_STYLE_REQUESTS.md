# Область действия RU/EN просьб о стиле — 2026.10.30.14

Добавлены 80 **авторских синтетических** фраз в 10 измерениях, двух значениях каждого измерения, двух языках и двух областях действия. Это 40 смысловых сочетаний (значение × область действия), по одному примеру на язык. Дополнительного разрешения на действия и санкции нет. Все входы должны быть обращены непосредственно к ассистенту и полностью совпадать с проверенной фразой; цитаты, слова третьих лиц, условные или составные неизвестные команды не распознаются.

```python
from dialogue_preferences import PreferenceSession, load_preferences, load_scoped_requests
p = PreferenceSession(load_preferences(), scoped_book=load_scoped_requests())
p.observe_scoped("Только следующий ответ напиши совершенно серьёзно, без шуток.",
                 language="ru", addressed=True)
assert p.consume_for_reply()["humor"] == "disabled"
assert p.snapshot()["humor"] is None
p.observe_scoped("На протяжении этой беседы обойдись без шуточных отступлений.",
                 language="ru", addressed=True)
assert p.snapshot()["humor"] == "disabled"
p.clear()  # required when the isolated conversation ends
```

`one_reply` хранится исключительно до однократного `consume_for_reply()`; `session` действует только в памяти конкретного экземпляра до `clear()`. Обычные проверенные просьбы `observe()` перебивают прежнее сессионное правило этого измерения. `routing_hints(consume=True)` тоже одноразово снимает временное значение. При чувствительной теме `sensitive=True` запрещает юмор, мрачный юмор и мат независимо от opt-in; разрешение обычного юмора само по себе не открывает мрачный. Разрешённые фразы о мате не разрешают адресные оскорбления. Никакие пользовательские ID, история сообщений или ключи доступа не сохраняются.

Граница применимости: это детерминированные подтверждённые выражения, а не модель общего понимания или лицензия на новое поведение у работающих ImPULS/AuroraFox. Каждый consumer обязан вызвать чтение пакета из локального валидированного снимка, создать отдельный объект на чат, завершить ответ с `consume_for_reply` и очистить объект при завершении беседы.
