# ImPULS: право удаления сообщений

В `packs/ru/impuls_help_qa.json` добавлен один обезличенный ответ о праве `can_delete_messages` в супергруппе. Проверенный источник: [Telegram Bot API, deleteMessage](https://core.telegram.org/bots/api#deletemessage). Это синтетическая проверка пути обучения и публикации, а не пользовательская переписка или реально выученный факт. Исходный кандидат создан в локальной базе ImPULS, экспортирован, проверен по первоисточнику и опубликован как `verified_source` через доверенный издатель. Локальная база, ID пользователя и исходная переписка в репозиторий не попали.

Назначение: только справка ImPULS при прямом обращении. Запись не даёт боту или человеку право удалять сообщения и не меняет настройку чата. Для другой аудитории запись скрыта. Версия `2026.11.06.039`; хеш пакета указан в манифесте.

Локальная проверка: `python -B scripts/validate_pack.py` и десять независимых построений каталога/индекса ImPULS 1.6.242. Точный вопрос и один смысловой вариант дали правильный ответ; для `all_ai_bots` результат и ответ отсутствуют. Медиана/максимум поиска: 19,302/33,621 мс; формирования ответа: 0,430/12,630 мс на локальном ПК. Проверка живого BotHost остаётся отдельной: его доставка Git на момент PR не подтверждена.
