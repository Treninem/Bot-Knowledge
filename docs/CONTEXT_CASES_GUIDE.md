## Формат / использование
Каждый кейс имеет `id`, `category`, `audiences`, `context`, `input`, `decision`, `expected_behavior`, `forbidden_behavior`. Это размеченные **синтетические сценарии**, а не реальная история чата или команды. Решения: `answer`, `clarify`, `abstain`, `human_review`, `refuse_claim`. Назначения: `all_ai_bots`, `chat_moderators`, `community_bots`.

Нельзя выдавать наличие кейса за то, что бот успешно его выполнил. Реальная модель должна быть проверена отдельно: подавать контекст/реплику и оценивать ответ по ожидаемому/запрещённому поведению; **данная структурная проверка не тестирует качество модели**.

## Проверка без повторов
1. Отдельные ID и уникальные сообщения во всех 80 сценариях.
2. Ровно 10 тематик × 8 новых кейсов; новый набор **не дублирует** ранее существующие skills в формате коротких готовых ответов.
3. Проверка SHA-256 файла по манифесту, типов полей, допустимых назначений, запрета автоматических санкций, неизменности публичной безопасности.
4. 10 циклов детерминированных структурных проверок `scripts/test_context_cases.py`. Это 10 повторений **проверки пакета**, не 10 успешных разговоров с ИИ.
5. Тест `scripts/validate_pack.py` проверяет новый тип пакета; остальные pack SHA и протоколы не меняются.

## Доставка и ограничения
- **Producer:** Bot-Knowledge хранит утверждённые версии. Потребителям отдавать только через существующий HTTPS + SHA-256 + локальный кеш, не на каждое сообщение.
- **ImPULS:** отдельный consumer PR для безопасного применения случаев в тестах/выборе ответа. Владелец бота и владелец чата — разные роли; секретное меню проверять по серверному идентификатору, кейсы никому права не дают.
- **AuroraFox:** только `all_ai_bots`; весь модерационный/чатовый материал исключается. Core и офлайн режим должны сохраняться.
- Ни реальных чатов, ни контактов, ни локальных правил, ни публикации от BotHost. Нет автоматического изменения санкций или аккаунтов.
- **Не объединять PR без реально завершившегося зелёного exact-head CI**. Если Actions не стартуют, отчёт должен сказать «проверки не выполнялись», а не «PASS».
