# RU/EN смысловые связи и естественные переходы — 2026.10.30.19

Новый пакет `packs/ru/discourse_links.json` содержит **30 оригинальных RU/EN синтетических задач** (по 15 на язык), **15 различных семантических отношений** и **90 одобренных регистровых формул перехода**. Это не 90 независимых смыслов и не универсальная языковая модель.

Модуль `scripts/discourse_links.py` возвращает **только предложенный вводный союз/связку**, не готовое предложение и не действие. API `DiscourseLinks.suggest(relation=..., confirmed_relation=..., language=..., register=...)` требует двух совпадающих *структурных* меток смысла. При отсутствии подтверждения, противоречии, неизвестной метке, цитате, неадресованности или повторе возвращает безопасный статус без связки. Модуль не анализирует произвольные фразы пользователя, не хранит сообщения, не общается с сетью и не выполняет модерацию.

Отношения: addition, contrast, concession, cause, result, condition, exception, sequence, example, reformulation, correction, alternative, summary, comparison, simultaneity. Особенно важно не путать **cause/result**, **contrast/concession**, **sequence/simultaneity**, **example/summary**, **reformulation/correction**. В таблице у каждого примера есть смысловой критерий `usage` и отдельное `avoid` с ошибочным прочтением.

Пример локального вызова:

```bash
python scripts/discourse_links.py --relation concession --confirmed-relation concession --language ru --register neutral
python scripts/discourse_links.py --relation result --confirmed-relation result --language en --register formal
```

**Ограничения:** коннекторы имеют разную грамматическую конструкцию и пунктуацию. Потребитель отвечает за порядок частей, падежи, оформление и достоверность причинных связей; нельзя механически вставить `Если`, `Поскольку` или `Кроме` между любыми двумя текстами. Если семантическое отношение не установлено, лучше отказаться от автоматического соединения. Не разрешены пользовательские данные, полномочия, публикация в GitHub, санкции, межчатовые состояния. Для работы в ImPULS/AuroraFox нужна самостоятельная consumer-интеграция.

Проверки: `python scripts/validate_discourse_links.py`, `python scripts/test_discourse_links.py`, `python scripts/validate_pack.py`. Валидатор проверяет уникальные ID и нормализованные задачи, пересечения с другими утверждёнными пакетами и лексические почти-дубли по Jaccard ≥0,85 (не доказательство абсолютной семантической уникальности). Модуль проверяет SHA-256 из manifest. Тесты выполняют все 90 одобренных вариантов, 450 контрастных защитных случаев, 10 повторных проходов, 1000 вызовов и проверку повреждения файла. Измерения CI не являются измерениями реального бота.
