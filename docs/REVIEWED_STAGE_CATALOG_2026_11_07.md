# Read-only ReviewedStageCatalog — 7 ноября 2026

Этот отдельный **opt-in** пример показывает, как индексировать ранее проверенную цепочку T305–T325 (разговорные выражения) и T306–T326 (практическая помощь) без клонирования канонических вопросов и без расширения формата `qa.v1` выше девяти зарегистрированных ответов.

Исходный main: `9c33776f15503ba669b589aee7b5ba18f5635562`. Количество строго ограничено **1310 отдельных staged-ответов к 46 стабильным намерениям**: разговорные 22×29=638, практические 24×28=672. Включая ранее зарегистрированные 9 на намерение, исторический учебный корпус этих двух групп составляет 1724/4600; **новых текстов в этой технической партии — 0**. Данные новых текстов T325/T326 объединены отдельным PR #374.

`ReviewedStageCatalog(ROOT)` вызывает `Stage("T325")` и `Stage("T326")` до построения индекса. Эти валидаторы рекурсивно проверяют все родители и реальные Git blob/SHA источников, контрольные точки, приватность, ответную аудиторию, read-only и отсутствие известных дублей. Индекс формируется локально из явно названных путей, без сетевых запросов в ходе ответа, без чтения пользовательских чатов и без модерации.

Пример:
```python
from scripts.reviewed_stage_catalog import ReviewedStageCatalog
catalog = ReviewedStageCatalog()
selection = catalog.select(
    "ru_turn_no_question",
    approved_reply_ids=frozenset({"ru_turn_no_question_t325_01"}),
    audience="all_ai_bots", context="private",
    addressed=True, local_permission=True, recent_ids=(),
)
# selection: StagedSelection or None. No action can be executed by it.
```

**Важно:** `approved_reply_ids` должен быть вычислен внешним доверенным потребителем *после независимого подтверждения смысла заметки, адресации, контекста, роли и разрешения*. Нельзя доверять ID, присланным в обычной реплике или цитате. При отсутствии разрешения, неверном контексте/аудитории, повторе ID или неизвестном намерении метод возвращает `None`. Межчатовой памяти и автоматического обучения нет.

Тест: `python -m unittest scripts.test_reviewed_stage_catalog -q`. Проверяются все 1310 ID, поиск среди ранних и новых стадий, явное разрешение/отказ, инвалидация контроля при изменённом родителе и read-only полный inventory. Без exact-head и post-main CI публикация не считается проверенной. Manifest, пакеты, кэши, ImPULS и живые боты не изменяются: это **референсный код**, а не подключённая интеграция.
