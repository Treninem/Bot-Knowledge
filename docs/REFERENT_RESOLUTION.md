# Проверяемый выбор объектов из контекста (v2026.10.30.7)

\`scripts/resolve_referents.py\` — реальный локальный детерминированный резолвер для коротких RU/EN обращений. Он получает от приложения **уже разрешённый, кратковременный** список кандидатов \`id/label/gender\` и возвращает только список ID либо безопасный отказ. **Ничего не редактирует, не отправляет, не модерирует и не хранит.**

\`packs/ru/referent_resolution.json\` содержит 50 новых авторских синтетических контекстных проверок (25 RU, 25 EN) по 8 областям: порядковые/последний; «не A, а B»; оба/все/кроме; явные названия; местоимения/род; отсутствие контекста/двусмысленность; цитаты; запреты и подтверждение опасных операций.

**Границы:** поддержаны только явно заданные формы, не полноценный грамматический анализатор. «Этот», «тот», «другой» при нескольких кандидатах не разрешаются по догадке. «Не удаляй» и *do not delete* не выбирают объект. «Удали» и *delete* только возвращают \`confirm_required\`, действие в коде отсутствует. Приложение обязано отдельно проверить намерение, права, контекст/TTL и получить подтверждение. Без \`addressed=True\` модуль молчит.

**Проверка:** каждая из 50 ситуаций передаётся в настоящую функцию с сопоставлением ожидаемых ID и статуса; отдельные незнакомые фразы проверяют переносимость правил. Тест проверяет подмену SHA, нормализованную уникальность, невалидные кандидаты, 10 повторных циклов и 1000 локальных вызовов. Это не измерение живого ImPULS/AuroraFox.

Пример:

\`\`\`sh
python scripts/resolve_referents.py --addressed --language ru --message "Нет, не первый, а второй." --candidates-json '[{"id":"a","label":"макет альфа","gender":"m"},{"id":"b","label":"макет бета","gender":"m"}]'
\`\`\`

Ожидается \`{"status":"resolved","ids":["b"]}\`. Идентификатор **не выполняет** изменение. Каждый consumer должен самостоятельно подключить новую версию по HTTPS+SHA и сохранить безопасный fallback.
