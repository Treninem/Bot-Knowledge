# Проверка публичного бесплатного CI для PR #230 · 2026-11-05

Выявлено, что ранее подготовленные T141/T142 commits имели `[skip ci]`; это оставляло **0** exact-head runs и блокировало публикацию. Сверено: публичный Bot-Knowledge использует стандартный `ubuntu-latest`, workflow имеет `permissions: contents: read`, проверяет `git rev-parse HEAD` против head PR, использует `persist-credentials: false` и не выдаёт токены записи недоверенному коду. GitHub официально считает стандартные hosted runners публичных репозиториев бесплатными; пользователь не разрешал платные Actions.

Один новый commit без `[skip ci]` включает уже созданные регрессионные Python-проверки T125/T126 в точный CI (после обязательной проверки SHA/JSON). В workflow нет секретов, платных runner-типов и ослабления защит. Рабочие кэши потребителей не затронуты. **Само наличие workflow не является PASS**: дождаться фактических run/check и сверить полный checkout head SHA.

CI подтверждает структуру, но не отключает обязательные смысловую экспертизу и consumer E2E. Даже при зелёном exact-head PR #230 остаётся Draft/BLOCKED, если ImPULS не умеет безопасно загружать и выбирать staging-кандидатов.
