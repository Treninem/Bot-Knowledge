# RU/EN: точный выбор близких выражений (2026.10.30.10)

## Реальные данные
- 12 разных смысловых семейств, в каждом по 3 **различающихся значения**.
- 72 оригинальные синтетические ситуации (36 RU + 36 EN) и 216 уникальных утверждённых формулировок (по 3 регистра: neutral, formal, casual).
- Межпакетных дубликатов нормализованных исходных примеров при добавлении: 0. Валидация пересчитывает это при каждом запуске.
- Примеры охватывают глубину проверки, уверенность, силу просьбы, обратную связь, ошибки, время, масштаб изменений, согласие, эмоции, юмор, силу доказательства и статус выполнения.

## Рабочий механизм, а не имитация NLP
`scripts/word_nuances.py` выбирает выражение **только по явно подтверждённым** `family` + `sense`, языку и тону. Не распознаёт произвольное сообщение самостоятельно, не гадает по недостаточным признакам и не утверждает, что факт проверен. Для одной темы разные смыслы действительно дают разные тексты. При отсутствующем смысле возвращается `needs_semantic_context`.

Пример:
```bash
python scripts/word_nuances.py --family review_depth --sense skim --language ru --tone casual
python scripts/word_nuances.py --family review_depth --sense verify --language en --tone formal
python scripts/word_nuances.py --family progress --sense planned --language ru
python scripts/word_nuances.py --family progress --sense complete --language en
```

Смыслы нельзя подменять: «запланировано» не равно «завершено», «заметил» не равно «обвинил», «возможно» не равно «подтверждено», «бегло изучил» не равно «провёл аудит». В формулировках о фактах сам потребитель обязан подтвердить состояние внешнего мира: библиотека выдаёт только лексический вариант, не доказательство.

## Безопасность и ограничения
Файл `packs/ru/word_nuances.json` SHA-256-проверяется по `manifest.json`. Мрачный юмор и сильная эмоциональная тональность требуют явного opt-in; в чувствительном контексте юмор подавляется. Селектор только возвращает строку: **никакой модерации, наказаний, действий или персональной памяти**. Данные не содержат реальных диалогов, имён пользователей, секретов, логов. Интеграция с ImPULS/AuroraFox не выполнена.

## Проверка
```bash
python scripts/validate_pack.py
python scripts/validate_word_nuances.py
python scripts/test_word_nuances.py
```
Тесты исполняют 10 циклов по 72 смыслам × 3 регистра, 1000 локальных выборов, поиск 72 исходных фраз, запрет смешения значений, отказ при неизвестном смысле, SHA и защитные ограничения. Цифры скорости GitHub runner нельзя приписывать реальным устройствам.

## Подключение потребителя
Потребитель подтверждает семантические признаки, берёт одобренную строку из локального кеша с проверкой версии и SHA-256 и хранит личный контекст у себя. Для произвольной речи нужны отдельные классификатор, валидация смыслов на новых текстах и регрессионные тесты. Ответы не должны быть навязчивыми.
