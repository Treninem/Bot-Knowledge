Приоритет — реальная диалоговая уместность: поддержать без непрошеных советов, поздравить без выдуманных достижений, принять исправление смысла, остановить личные оскорбления без ответной травли, ответить на запрос юмора и написать короткую авторскую миниатюру. Каждый случай размечен `context`, `input`, `response`, `avoid`, `kind`, `audiences: ["all_ai_bots"]`. Разделы независимы от ImPULS: нет неподтверждённых команд, ссылок на приватный код или обещаний изменить настройки.

Границы выбора: `humor` — только при явном запросе и в несерьёзном контексте; `profanity` — вежливые границы при грубости, без травли и санкций; `support` — без медицинских и иных необоснованных выводов; `creative` — вымысел, не реальный факт; `conversation` — уточнение при недостающем контексте вместо угадывания. Языковой пакет не производит действия, не запоминает переписки и не передаёт данные между потребителями.

Проверка: `python scripts/validate_pack.py`, `python -m scripts.test_social_dialogue_t54`. Второй тест проверяет SHA-256 реального байтового файла, размер меньше 2 MiB, ровно 72 уникальных ID, нормализованные дубли входов и ответов по всему пакету, присутствие нужных полей, аудиторию, приватность, отсутствие санкций и локальное нахождение каждой новой записи. GitHub Actions: точный PR head, затем отдельный post-main run после успешного merge. Consumer-интеграция и реальный BotHost не изменены и не проверяются этим тестом.
