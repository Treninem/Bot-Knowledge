# Контекстное числовое исправление RU/EN — 2026.10.30.15

Существующие модули отслеживают объект разговора, смысл синонимов и временный стиль, но не умеют **безопасно исправлять прежнее числовое ограничение**. Новый `scripts/numeric_repair.py` реализует ограниченное грамматическое обобщение: числа от 0 до 9999 в четырёх русских и четырёх английских конструкциях. 48 авторских синтетических кейсов: 24 RU, 24 EN; из них 24 подтверждённых исправления и 24 отказа/защитных случая. Шесть бытовых категорий: количество пунктов, длительность, шаги, примеры, страницы и копии. Это **не** 48 новых самостоятельных универсальных правил языка и не модель произвольного понимания.

Вызывающая программа **сама** определяет язык, точную словоформу единицы измерения, идентификатор поля и подтверждённое прежнее значение. Для нового выражения с другой числовой величиной достаточно совпадения с одной из ограниченных грамматик. Старое число обязательно должно совпасть с текущим значением: иначе возвращается `stale_context`. Лишние команды, цитаты, неизвестные обороты, отрицательные числа, другая единица, неоднозначные «или» и отсутствие адресации не приводят к изменению.

Пример локального использования (только после проверки SHA-256 через манифест):

```python
from numeric_repair import NumericRepair
parser = NumericRepair()
current = {"pages": "5"}
proposal = parser.propose("Не 5, а 10 страниц.", language="ru",
                          state=current, slot="pages", unit="страниц", addressed=True)
assert proposal["status"] == "updated" and proposal["state"]["pages"] == "10"
assert current["pages"] == "5"  # оригинал никогда не изменяется
```

Модуль **предлагает** новое значение; только конкретный consumer после отдельной проверки вправе сохранить его. Он не исполняет пользовательские команды, не выдаёт санкции, не знает контекста сообществ, не хранит переписки и не обращается к сети. Для каждого чата вызывающий сервис обязан изолировать собственное состояние и проверять правомочность изменений. Не применять алгоритм к суммам денег, измерениям для безопасности, лекарствам, техническим настройкам и другим высокорисковым областям без специальной доменной проверки.

Верификация: `python scripts/test_numeric_repair.py` (48 кейсов × 10 циклов, самостоятельные неизвестные числа, отрицательные примеры, SHA и поисковый индекс), `python scripts/validate_pack.py`, весь CI. Никаких изменений в ImPULS или AuroraFox этим PR не производится.
