## Quality and trust gates

- New variants depend on explicitly stated situations, not cosmetic emoji, shuffled syntax or generic synonyms. No private chat transcripts, identifying facts, unverifiable ImPULS functions, sanctioned moderation actions or tokens are included.
- `scripts/context_overlay_t300.py` validates the entire prior T299 chain, exact parent blob, all registered source SHA-256s, historical counts, normalized global text/ID uniqueness, per-intent context-note uniqueness, normalized text and token overlap, and completion of exactly 15 intents.
- New replies are opt-in staged proposals only: matching direct address, trusted explicit reply-ID allowlist, matching context channel and local permission. It is not an autonomous moderation engine or consumer integration.

- Exact-head Python validation is required before merge: `python scripts/validate_pack.py`, `python -m unittest scripts.test_context_overlay_t300 -q`, under read-only Actions verifying `git rev-parse HEAD`. Post-main checks must be run on the *actual merge SHA* before calling publication confirmed.
