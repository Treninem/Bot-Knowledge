По группам: восстановление после сбоев **24**, обоснованный выбор **30**, редактура/факты/границы разговора **31**. Новые ситуации включают различие сети и приложения, безопасную диагностику, экономические обязательства, доступность интерфейса, пределы гарантий, частичные статусы, неполные цитаты, фактическую неопределённость и деэскалацию. ID продолжены `<intent_id>_t241_12` внутри существующей схемы. Наличие отличающихся формулировок не доказывает отсутствия всех смысловых дублей — нужен содержательный просмотр. Новые `context_note` не совпадают с прежними внутри соответствующего intent. `scripts/test_context_delta_t257.py` проверяет все счётчики, общий инвентарь, назначение, SHA-pinned parent stages через `StagedContextDelta`, приватность и отказ без локального одобрения. Прежние T241–T247 проверки сохраняют проверку своих исторических ID и обновлены для возросшего общего инвентаря.

**Ограничения:** не регистрируется в `manifest.json`, не меняет SHA-256 действующих пакетов, cache, ImPULS или живых ботов; consumer integration отсутствует. Только после успешного exact-head CI и проверки актуального main возможен merge; затем отдельно проверяется post-main CI.
