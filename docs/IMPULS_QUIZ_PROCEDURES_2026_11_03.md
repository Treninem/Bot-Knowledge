# ImPULS: управление викториной

Две записи в `packs/ru/impuls_help_qa.json` объясняют пользователю, как владелец чата включает и выключает викторину. Это справка, а не разрешение боту менять настройки по записи из БК.

Проверено по исходникам ImPULS main `9a704b0375d0b06463a12ee5e3c3c8bd4d668451` (03.11.2026): обработчик `src/bot/handlers/team_quiz_group.py` принимает в группе точные команды «викторина включить» и «викторина выключить»; сервис `src/bot/services/team_quiz.py` допускает изменение только при текущем статусе Telegram `creator`. Выключение закрывает активные игры этого чата. После включения участник запускает раунд сообщением «викторина».

Записи ограничены аудиторией `impuls`, читаются без исполнения действий и не содержат частных данных. При изменении команд в ImPULS сведения нужно пересмотреть; публикация PR и CI сами по себе не подтверждают работу на BotHost.
