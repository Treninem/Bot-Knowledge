# T144 — исправление обнаруженной ошибки CI · 2026-11-05

Проверен реальный exact-head workflow run [42024929050](https://github.com/Treninem/Bot-Knowledge/actions/runs/42024929050) для T143 head `195297e88610b2504c4c62e82200393fff8466df`. Ошибка в `scripts/test_extended_knowledge.py`, где общая QA-проверка ещё требовала **строго два** варианта на каждую запись, хотя `qa.v1` допускает до восьми и ветка содержит новые легальные варианты. Выполненные ранние шаги, включая `scripts/validate_pack.py`, прошли; Python-тест T126 не успел начаться из-за раннего сбоя.

Исправлено узко: сохранены строго два алиаса, `all_ai_bots`, требование уникальности нормализованных вариантов; вместо ровно двух вариантов проверяется **от 2 до 8**. Итоговая диагностическая строка теперь считает вопросы, алиасы и ответы из фактического пакета, а не старую константу 30/60/90. Исправление проверено по сообщению об ошибке из реального CI, но будет считаться успешным только после нового run.

T126/T125 перемещены сразу после `validate_pack.py`, чтобы они выполнялись даже если другие поздние регрессии упадут. Workflow остаётся `pull_request`, `permissions: contents: read`, `ubuntu-latest`, exact-head checkout, без секретов и без платных runner-типов. Изменения данных/manifest и приватного ImPULS не проводились.
