# Разрешения владельца для самостоятельного пополнения Bot-Knowledge

Действует с **02.11.2026** по прямому поручению владельца репозитория. Область: **только Treninem/Bot-Knowledge**, не распространяется на private Treninem/Impuls, живые боты, BotHost, AuroraFox, развёртывание, реальные платежи или платные сервисы.

В рамках этой задачи авторизовано систематическое пополнение оригинальных обезличенных разговорных данных и навыков, исправление тестов и документации, обновление и разрешение конфликтов PR, перевод проверенных Draft в ready, самостоятельный merge проверенных PR и закрытие действительно завершённых/дублирующих/заменённых PR и issues. Предыдущие локальные ограничения «только аудит», «только минимальная тестовая партия» и «никаких самостоятельных merge» не являются действующими запретами *для этой задачи и этого репозитория*. Цель — максимальный проверенный полезный объём без искусственных квот, но без набивки синонимов.

**Неприкосновенные требования безопасности:** публичная база содержит только синтетические оригинальные обезличенные данные; нельзя копировать реальные переписки, ID, секреты, цитаты чужих защищённых текстов; языковой пакет не исполняет санкции. Бот-потребитель имеет только чтение, локальные права проверяются отдельно. Изменения ImPULS — только чтение, без самостоятельного деплоя. Не обходить GitHub branch protection, required checks и тайны.

**Merge gate остаётся обязательным:** проверка актуальных main/base/head SHA; локальные или реальные GitHub тесты без выдуманных PASS; совпадение manifest и SHA-256 для зарегистрированных пакетов; окончательный exact-head CI на actual checkout head SHA; корректное поведение при ошибках; guarded merge с ожидаемым head; post-main CI на фактическом merge SHA. Если обязательная проверка недоступна, PR остаётся BLOCKED, а уже проверенный материал сохраняется отдельно. После merge не считать staging доступным живому потребителю без явной регистрации и consumer-теста.

**Учёт партии:** новые ответы считаются только по дельте, контекстно разные варианты сохраняют стабильные intent ID, а незаконченный набор фиксирует точные счётчики, head SHA, ветку/PR и следующее действие. При закрытии PR/issues ссылка на сохранённое уникальное изменение и объяснение обязательны. Текущая работа по T560–T561 оформлена в PR #596.

Данная фиксация разрешений не отменяет `AGENTS.md`, `POLICY.md`, `docs/REQUIREMENTS_21.md`, а уточняет статус прежних ограничений на инициативу/слияние.
