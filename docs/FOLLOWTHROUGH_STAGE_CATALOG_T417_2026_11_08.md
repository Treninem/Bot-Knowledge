# Полный локальный followthrough-каталог T383–T417 (08.11.2026)

Ранее справочный каталог содержал 33 этапа T383–T415. Этот PR включает
**T416 и T417**, уже подготовленные в двух отдельных PR, и не создаёт
ни одного нового ответа. Теперь в локальном каталоге **35 стадий**,
**3034 staged-ответа** для **82** исходных намерений, по **37 staged**
плюс **3 зарегистрированных** ответа на намерение = **40/100**.
Всего 3280/8200; осталось **4920**, или по 60 для каждого.
Новых завершённых наборов 100/100: 0.

`scripts/staged_context_selector.py` явно разрешает только точные пути
T416/T417 и жёстко закреплённые Git blob SHA-1
`f040d11225642a5c25adad50d5cc79f56526b0b1` и
`dd6102212e9be4e467b79825f5e9fb77a618e5ac`.
Для каждого этапа проводится проверка полной родительской цепочки,
кэша на байтах, канонических вопросов, ограничений аудитории и локального
разрешения. Неверный SHA или повреждённая стадия отклоняются.
Каталог запрещает повтор ID/текста, не допускает санкций и возвращает
ответ только при `approved_reply_ids`, `addressed=True` и
`local_permission=True` с верной аудиторией и контекстом.

Обновлён существующий тест
`python -m unittest scripts.test_followthrough_stage_catalog -q`.
Он проверяет каждую запись 35 стадий, точное разрешение,
запрет чужого намерения и повторов, изменение любого staged-файла,
изменение исходника и тысячу последовательных локальных чтений.
Общий источник и manifest SHA-256 не меняются, кэш работающих ботов
не трогается. Это **справочный opt-in код**, не подключение ImPULS.
