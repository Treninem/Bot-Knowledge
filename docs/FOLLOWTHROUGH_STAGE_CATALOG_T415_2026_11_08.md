# T383–T415: полный локальный справочный каталог (08.11.2026)

Ранее `FollowthroughStageCatalog` содержал только 23 стадии T383–T405 (1968 staged-ответов) и не находил явно разрешённые ответы T406–T415. Теперь индекс включает 33 стадии T383–T415: **2870 уникальных staged-ответов для 82 намерений**, то есть 35 staged + 3 зарегистрированных на намерение = **38/100**. Новых ответов этим кодовым изменением не добавлено; данные T406–T415 уже существуют в отдельных PR/коммитах, они не должны пересчитываться как новые.

Каждая стадия загружается через `StagedContextSelector`, который сверяет точные Git blob SHA, исходный manifest SHA-256, родительские стадии, 82 canonical ID, содержание и разрешения. Каталог проверяет уникальность ID и нормализованных текстов между стадиями и вычисляет локальный cache identity по содержимому. `select()` по-прежнему отклоняет неизвестное намерение, чужой контекст/аудиторию, неадресованное сообщение, неверный тип `approved_reply_ids`, отсутствие явного локального разрешения, недавно использованный ID. Это **локальный read-only справочник** для проверенного потребителя, а не автоматическое подключение к ImPULS.

Тест `python -m unittest scripts.test_followthrough_stage_catalog -q` проверяет выбор каждого ответа только после явного разрешения, 1000 локальных чтений, отказ без контекста/разрешения, обнаружение подмены source или любого из 33 staged-файлов, 82 canonical ID и 2870 unique staged replies. Нет изменений зарегистрированных pack/manifest, живых кэшей или ботов. Требуется actual exact-head CI, post-main CI, проверка совместимости с базой после #469. История нескольких крупных стадий может делать первичную загрузку долгой; горячий поиск после инициализации не обращается в сеть.
