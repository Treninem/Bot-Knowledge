# Выбор выражений и разговорная вариативность — 30.10.2026

Содержимое: **30 независимых речевых ситуаций**, по одному варианту в каждом из трёх тонов на русском и английском — **180 оригинальных формулировок**, не извлечённых из приватных сообщений. Новый файл `packs/ru/expression_choices.json` отделён от прежних `skills.json` и `social_dialogues.json`; старые пакеты не заменены.

## Что реализовано прямо сейчас
`scripts/choose_expression.py` — работающий **локальный детерминированный селектор**. Выбор требует точного `scenario`; программа проверяет SHA-256 пакета из манифеста, язык (`ru` или `en`), тон (`neutral`, `warm`, `casual`) и разрешения на сильную лексику/чёрный юмор. Опасный/чувствительный контекст подавляет такие варианты даже при согласии. Повтор последней формулировки не отправляется автоматически: возвращается `no_unused_phrase`, если альтернативы для данной пары `scenario/tone` исчерпаны.

Пример:
```sh
python scripts/choose_expression.py --scenario expr_correct_own_error --tone casual
python scripts/choose_expression.py --scenario expr_dark_humor_requested --tone warm --dark-opt-in
python scripts/choose_expression.py --scenario expr_dark_humor_requested --dark-opt-in --sensitive
```

Все примеры и шаблоны **не дают права** писать от лица администратора, применять наказания, раскрывать секреты, предпринимать действия в GitHub или самостоятельно вмешиваться в беседу.

## Что пока не реализовано
- Автоматическое определение эмоции, намерения, сарказма или полноты контекста из произвольного текста: для этого нужен проверенный NLP/consumer и отдельные реальные поведенческие тесты.
- Подключение к ImPULS, AuroraFox или другим запущенным приложениям; наличие пакета не активирует функцию.
- Полноценная модель, сочиняющая любую фразу: здесь намеренно ограниченная проверенная библиотека. Для генерации на ходу нужна отдельная языковая модель с проверкой контекста и ограничений.

## Правила расширения
Не добавлять дословные дубли, одинаковые мысли с заменой одного слова или придуманные «тесты модели». При необходимости новых формулировок сперва расширять различимые намерения и примеры, затем мерить на независимых фразах. Проверка реального селектора: `python scripts/test_expression_choices.py`.
