# Кратковременные RU/EN предпочтения общения — 2026.10.30.13

Реальный модуль `scripts/dialogue_preferences.py` распознаёт **только точные утверждённые** формы явного предпочтения: вопросы, юмор, мат, мрачный юмор, предложения, приветствия, краткость, официальность, эмодзи, метафоры. В `packs/ru/style_preferences.json` — 10 измерений, 20 различных смысловых состояний, 40 комбинаций состояние/язык, 80 оригинальных синтетических реплик (40 RU и 40 EN). Два варианта одного смысла — две фразы, но **не два разных умения**.

Использование:

```python
from dialogue_preferences import load_preferences, PreferenceSession
session = PreferenceSession(load_preferences(), ttl_turns=12)
session.observe("Без эмодзи, пожалуйста, только текст.", language="ru", addressed=True)
assert session.snapshot()["emoji"] == "disabled"
session.advance()   # один раз за каждый последующий пользовательский ход
session.clear()     # при закрытии изолированной сессии
```

В памяти хранятся **только** (измерение, значение, номер хода), без истории, пользователей, чат-идентификаторов и диска. Каждый потребитель создаёт отдельный экземпляр на беседу, вызывает `advance()` и очищает его при завершении; после 12 последующих ходов предпочтение истекает. `quoted=True` игнорирует даже точное совпадение. Неодобренные, составные и приблизительные фразы не распознаются; новое прямое предпочтение заменяет прежнее.

Разрешение обычного юмора не означает согласие на мат или мрачный юмор. `routing_hints()` по умолчанию оставляет сильную лексику и чёрный юмор выключенными, а `sensitive=True` блокирует их вместе с обычными шутками даже после opt-in. Запрет необязательных вопросов не отменяет необходимых уточнений безопасности. Библиотека ничего не отправляет, не наказывает, не исполняет команды и не меняет полномочия. Точное распознавание примеров **не равно NLP для произвольного текста**.

Проверки: `python scripts/validate_pack.py`, `python scripts/validate_style_preferences.py`, `python scripts/test_style_preferences.py`. Они включают поиск, SHA-256, уникальность ID и нормализованных входов относительно прежних пакетов, изоляцию, цитаты, нежелательные добавления, обновление и истечение, 10 прогонов и 1000 локальных вызовов. Времена GitHub runner не означают работу на реальных устройствах. Consumer-интеграция ImPULS и AuroraFox остаётся отдельной задачей.
