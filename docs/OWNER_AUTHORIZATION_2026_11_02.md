# Уточнение полномочий владельца для работы с Bot-Knowledge

Владелец 02.11.2026 прямо разрешил в рамках задачи **только `Treninem/Bot-Knowledge`** систематическое расширение оригинальных обезличенных FAQ/языковых наборов и самостоятельные проверенные PR, merge, разрешение конфликтов и мотивированное закрытие действительно завершённых либо дублирующих PR/issues. Прежний временный запрет на массовое наполнение и необходимость нового персонального подтверждения для каждого слияния более не действуют для этой задачи.

Это **не** разрешение публиковать сырые чаты, секреты, личную память или неподтверждённые функции; обходить branch protection, exact-head CI, контроль SHA-256, аудит scope, защиту приватности; выполнять платные Actions; изменять `Treninem/Impuls`, деплоить приложения или автоматически раздавать навыки живым ботам.

Указанный выше мандат относится к проверенной работе разработчика/помощника от имени владельца. Он **не отменяет** защиту будущего доверенного publisher и запрет самостоятельной публикации чат-ботом без owner/reviewer gate. Любые будущие кандидаты из пользовательских разговоров по-прежнему требуют локальной приватной обработки, обобщения, удаления идентификаторов и отдельного контролируемого потока; права записи на GitHub не выдаются потребителям.

В случае несовместимых старых записей о запрете merge или объёмного наполнения в журналах этот актуальный мандат применяется только к одобренным синтетическим изменениям указанного репозитория, при сохранении остальных положений `AGENTS.md`, `POLICY.md` и `docs/REQUIREMENTS_21.md`.
