# Контекстные короткие ответы RU/EN — 2026.10.30.20

Пакет `packs/ru/short_turns.json` содержит **48 оригинальных синтетических коротких реплик** — 24 RU и 24 EN — для **12 смысловых категорий** (по две разговорные формы на категорию и язык). Это лексические альтернативы, а не 48 самостоятельных намерений. Примеры намеренно короткие, поскольку `да`, `no`, `ну` и `ok`-подобные формы нельзя интерпретировать без контекста. Для каждой реплики сохранена своя искусственная ситуация и граница значения. Никаких переписок или данных пользователей.

`scripts/short_turns.py` — **не модель языка и не обработчик команд**. Метод `ShortTurns.interpret(message, pending_kind=..., language=..., pending_turns=...)` распознаёт только явно одобренные фразы с подтверждённым типом ожидаемого вопроса. Контекст задаёт consumer: `confirmation`, `choice`, `information`. Нет контекста, прошло более двух ходов, меняется язык, пришла цитата/вопросительная интонация, ответ неоднозначен либо в нём есть лишние слова — отказ или предложение уточнить. `both` разрешено только для множественного выбора. Любой запрос с `side_effects=True` блокируется. Возвращаемый `action_authorized` всегда `False`. Никакой записи/санкций/отправок/платежей, хранения чатов, сетевого трафика или GitHub write-token.

```bash
python scripts/short_turns.py --message "ага" --pending-kind confirmation --language ru
python scripts/short_turns.py --message "option two" --pending-kind choice --language en
```

Исправлен пробел локального индекса: короткие запросы без токенов длиной три символа теперь могут находить **точное одобренное выражение**, но не запускают распознавание вне подтверждённого контекста. Поиск — подсказка, не доказательство пользовательского намерения.

Проверки: `python scripts/validate_short_turns.py`, `python scripts/test_short_turns.py`, `python scripts/validate_pack.py`. Проверяются все 48 реплик, устаревший/отсутствующий контекст, выбор, язык, цитаты, вопросы, лишние команды, отсутствие полномочий, подмена хэша и 10 циклов исполнения. Полная смысловая непохожесть двух переформулировок с одним намерением не предполагается. Реальные ImPULS/AuroraFox получат эти навыки **только после отдельной интеграции и проверки на целевой системе**.
