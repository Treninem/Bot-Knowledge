# Консервативный роутер диалога (v2026.10.30.6)

## Реализовано

- 60 **новых авторских формулировок входящих сообщений** (38 русских, 22 английских), сопоставленных с 30 уже проверенными ситуациями. Это разные варианты пользовательских запросов, а не повторение 60 готовых ответов.
- `scripts/conversation_router.py`: единая локальная точка входа для `social_dialogues`, `english_dialogues`, `dialogue_triggers`, `expression_choices` и `pragmatic_contrasts`.
- Во всех пяти источниках проверяются SHA-256 из общего манифеста до использования данных.
- Известное двусмысленное выражение **не превращается в шаблонную похвалу**, когда контекста недостаточно. Модерационные случаи отправляются на проверку человека, без автоматического ответа и без санкции.
- Ответ появляется только при явном признаке обращения к боту (`addressed=True`); без него бот молчит. Никакого чтения чужих чатов или отправки сообщений нет.
- RU/EN, три тона, явное согласие на резкую лексику, подавление такого юмора в чувствительном контексте, защита от повторения предыдущего ответа. Если безопасного неповторяющегося варианта нет — честное `repeat_suppressed`.

## Запуск

```sh
python scripts/conversation_router.py --addressed --message "Снова упал тест, уже надоело."
python scripts/conversation_router.py --addressed --language en --message "Hey there!"
python scripts/conversation_router.py --addressed --message "Отличная работа." --context "Проект успешно запустился, команда благодарит автора за результат."
python scripts/test_conversation_router.py
```

## Что не сделано

Это **детерминированная реализация для известных формулировок**, не новая языковая модель. Не распознаёт произвольный русский/английский текст с точностью человека и не ведёт живой диалог сама. Не обучается без отдельного приватного контура, не записывает данные в GitHub, не меняет роли или санкции. Для ImPULS/AuroraFox нужны отдельные проверенные consumer-интеграции.

## Правило расширения

Триггер должен добавлять действительно новый вариант намерения и иметь существующую утверждённую цель. Если смысл неоднозначен — создать контрастивную проверку и отказ от догадки, а не агрессивный подбор по похожим словам. Никогда не копировать живую переписку в публичный Git.
