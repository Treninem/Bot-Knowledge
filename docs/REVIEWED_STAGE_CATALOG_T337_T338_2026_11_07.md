# Проверенный read-only каталог 1 954 staged-ответов (T337/T338)

Этот **эталонный локальный индекс** дополняет первоначальную идею [PR #375](https://github.com/Treninem/Bot-Knowledge/pull/375): использует все стадии T305–T337 и T306–T338, а не прежний неполный набор 1 310 ответов. Сохраняются 46 канонических намерений, 414 исходных зарегистрированных ответов отдельно и **1 954 staged-ответа** (946 разговорных + 1 008 практических).

`ReviewedStageCatalog` проверяет весь закреплённый набор стадий, цепочку Git blob SHA, зарегистрированные SHA-256 и настройки назначения; при расхождении отказывает. Никаких сетевых запросов при поиске, записей, модерационных санкций или выполнения команд. Потребитель должен **сам** подтвердить намерение, адресацию, канал, аудиторию, разрешение и точный одобренный reply ID; поиск не выводит права из чужих сообщений. Cache identity включает проверенную версию manifest и хэш содержимого всех staged-источников. Отдельного включения у ImPULS и других живых ботов нет.

Тесты: `python -m unittest scripts.test_reviewed_stage_catalog -q` и полный read-only workflow `reviewed-stage-catalog.yml`. Проверяются 46/1954, уникальность нормализованных текстов и ID, отказ без разрешения, перебор всех сохранённых вариантов, защита от подмены родителя.

Это заменяющее проверяемое развитие #375 без правок его ветки; закрывать прежний PR можно только после сохранения и проверки этих функций в новом PR и main. Новые ответы эта индексация не создаёт; данные T337/T338 см. [контрольную точку](CONTEXT_CONTINUATION_T337_T338_2026_11_07.md).
