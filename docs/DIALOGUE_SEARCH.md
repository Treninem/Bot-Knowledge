# Общий индекс новых диалоговых формулировок

После добавления `dialogue_triggers.json` возникла необходимость соединить 60 новых формулировок с общим поиском. Теперь `scripts/search_knowledge.py` индексирует `triggers`, сохраняет ссылку на утверждённый `target_case_id` и поднимает точные совпадения фразы на первое место после фильтра аудитории.

**Было:** 451 запись. **Стало:** 511 записей; прирост 60 записей — это ранее добавленные формулировки, а не 60 новых сгенерированных ответов.

Тест `scripts/test_dialogue_search.py` проверяет все 60 совпадений и их целевые сценарии, запрет выдачи закрытых модерационных примеров общему профилю и 10 детерминированных прогонов. `scripts/test_pragmatic_search.py` обновлён под новый размер индекса.

Диалоговый роутер дополнительно проверяет явно выбранный язык для контрастивных выражений: английскую фразу нельзя случайно обработать как русскую, и наоборот. Запрос не переводится автоматически. Для произвольной речи требуется отдельная модель или проверенный классификатор; этот индекс остаётся локальным и не выполняет сетевых запросов при каждом сообщении.

## Тест жизненного цикла локального cache — 31.10.2026

Обнаружен конкретный риск: глобальный `@lru_cache` метода `KnowledgeSearch.search` удерживает ссылку на каждый когда-либо использованный объект поиска. При периодической замене подтверждённого snapshot старые индексы могут оставаться в памяти, несмотря на освобождение их потребителем.

Кэш результатов поиска теперь привязан к экземпляру SHA-проверенного snapshot, ограничен 512 ключами и освобождается вместе с ненужным экземпляром. **Обновление проверенного manifest требует построить новый экземпляр `KnowledgeSearch`**; старый объект намеренно продолжает читать только старый снимок. Нельзя принимать новые данные при несовпадающем SHA-256. Новый тест `scripts/test_search_cache.py` проверяет освобождение старого экземпляра, отклонение подменённого пакета, принятие нового только с совпадающим SHA, разделение старого и нового поискового кэша и границу в 512 записей. Временный тестовый пакет существует только внутри `TemporaryDirectory`; он не добавлен в библиотеку.

Новых языковых пакетов и записей: **0**. Уже опубликованные SHA-256 всех 25 пакетов не меняются. Живые потребители не обновлялись, деплой/merge этой ветки запрещены без отдельного решения владельца.
