## Новое содержание

- В **зарегистрированный** пакет `packs/ru/dialogue.json` добавлен новый необязательный подраздел `agreement_catalog` с **98 новыми синтетическими русскими ответами**. Два прежних ответа `reactions.agreement` не изменены. Итого **100/100** для одного намерения `agreement`, 25 контекстов с 25 явными условиями выбора.
- Темы: краткое согласие, выбор варианта, план, изменение границ задачи, временный стиль, объяснение, исправление, неопределённость, тестирование, формат, черновик, приватность, чтение без записи, бюджет, групповое и частичное согласие, прекращение вопросов, сравнение, творчество, обучение, откат, перевод, сроки, безопасность, пауза. Контекст должен подтвердить consumer — **из фразы «согласен» его не угадывать**.
- Согласие на формулировку **не является** разрешением оплатить, отправить сообщение, изменить файл, наказать участника, публиковать сведения или объявлять всю группу согласной. Не использовать при цитате, отрицании, сложном запросе, просьбе молчать, чувствительной теме, неадресованности и отсутствии локального разрешения.
- Старые массивы `greeting` 100, `thanks` 2 + 98 отдельных contextual, `farewell` 2 + 98 отдельных contextual, `agreement` 2 оставлены неизменными. Новый `scripts/agreement_catalog.py` подключается **только явно**, привязывается к manifest SHA-256 и возвращает read-only текст без побочных эффектов. Старые селекторы могут продолжать читать пакет, игнорируя необязательное поле.
