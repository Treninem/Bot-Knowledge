# Проверка приватности кандидатов — 30.10.2026

Исправлены четыре регулярных выражения в `scripts/prepare_knowledge_candidate.py`: прежняя двойная экранизация слэшей делала распознавание сетевых ссылок, адресов, длинных числовых идентификаторов и секретов неполным. Регрессионные тесты `scripts/test_candidate_privacy.py` подтверждают **отклонение** синтетических примеров четырёх классов и **принятие** нейтрального примера, включая безобидный год.

Это дополнительный автоматический фильтр, **не доказательство полной анонимности**. Реальные переписки, частные цитаты и секреты обрабатывать запрещено. Флаг `reviewed=true` сам по себе не доказывает фактическую ручную проверку. Доверенный редактор обязан повторно оценить содержание до публикации. Удаление строки коммитом не стирает историю Git.

Путь: локальный абстрактный кандидат → редакторская проверка приватности и смысловых повторов → PR → зелёный exact-head CI → main → post-main CI. Ни один запущенный бот не получает GitHub токен записи.
